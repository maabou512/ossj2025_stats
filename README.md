## 📝 Sched イベントデータ抽出

イベント管理システム sched の印刷用ページから取得したHTMLデータをもとに、登壇者や企業情報を整理したJSONデータを作成し、対話形式で修正するための手順を定めます。

### 目的

Schedを使用したイベント（例：Linux Foundation のOpen Source Summit Japanなど）の公開スケジュールページからデータを抽出し、**登壇者名**および**所属企業・組織名**などを整理したJSONファイルとして取得すること（sched イベントの参加者情報をJSONデータ化すること）。

-----

### I. 準備

#### 1\. ファイルの準備

以下のPythonスクリプトファイルを用意します。

| ファイル名 | 役割 |
| :--- | :--- |
| `input.html` | イベントサイトから保存したHTMLデータ (インプット) |
| `extract_data_sched.py` | HTMLからJSONへデータを抽出するスクリプト (従来の「最初のコード」) |
| `update_data_sched.py` | 抽出したJSONデータを対話形式で修正するスクリプト (従来の「2番目のコード」) |

#### 2\. 環境構築

Python 3 がインストールされていることを確認し、必要なライブラリをインストールします。

```bash
pip install beautifulsoup4
```

-----

### II. データ抽出と自動解析（ステップ②）

このステップでは、HTMLファイルからセッション情報を抽出し、登壇者 (`speaker`) と企業名 (`company`) を可能な限り自動で解析します。

#### 1\. HTMLデータの取得（ステップ①）

イベントサイト（例：`https://events.linuxfoundation.org/open-source-summit-japan/program/schedule/`）にアクセスし、プログラムスケジュールの印刷アイコン等をクリックして表示された印刷用ページ（例：`https://ossjapan2025.sched.com/print?...`）を\*\*`input.html`\*\*というファイル名で保存します。

#### 2\. データ抽出の実行

`extract_data_sched.py` スクリプトを実行して、JSONデータを作成します。

| 項目 | 詳細 |
| :--- | :--- |
| **インプット** | `input.html` |
| **アウトプット** | `output_2025_with_id.json` |
| **実行コマンド** | `python extract_data_sched.py` |

#### 3\. 抽出されるデータの解説

出力されるJSONデータ (`output_2025_with_id.json`) には、以下の情報が格納されます。

| フィールド名 | 概要 |
| :--- | :--- |
| `data_id` | データを識別するためのID (1からの連番) |
| `s_datetime`, `e_datetime` | セッションの開始・終了日時 (ISO 8601形式) |
| `title` | セッションの完全なタイトル（元の情報） |
| `speaker` | 登壇者名のリスト（`title`内の `Speakers:` 欄から抽出） |
| `company` | **抽出ロジックによって自動解析された企業・組織名のリスト** |

#### 4\. 登壇者・企業名判定のパターン説明

`company` データの自動抽出は、`title` フィールド内のセッションタイトルと、登壇者・所属情報を含む部分（例: `Jim Zemlin, Executive Director, The Linux Foundation`）をもとに行われます。

自動抽出のロジックは、以下の原則で動作するよう調整されています。

  * **登壇者と組織名の分離**: 情報ブロックを最初のカンマ（`,`）で分割し、**最初のカンマ以降の全て**を企業・組織名候補として採用します。これにより、氏名や役割（`Executive Director` など）を除去します。
  * **企業名内のカンマ保持**: `Hitachi, Ltd.` や `Company Co., Ltd.` のように、**企業名自体に含まれるカンマも保持**されます。
  * **共同発表者**: `&` で区切られた複数の組織がある場合、それぞれを独立した企業として抽出します（例: `A & B` → `A`, `B`）。

#### 5\. 自動抽出の限界と注意点

抽出ロジックは複雑なパターンに対応していますが、**`title` データが標準化されていない**ため、完全に自動化することはできません。

  * **`Co., Ltd.` のデグレード**: 修正により大部分は解決しましたが、元のHTMLの書き方によっては、`Hitachi, Ltd.` のように企業名内のカンマが誤って処理され、**不完全な企業名**が抽出される場合があります。
  * **役割の残存**: 稀に、役割情報がカンマで区切られていない場合に、`company` フィールドに役割情報の一部が残存することがあります。

これらのケースに対応するため、次のステップで個別にデータを修正します。

-----

### III. データの手動修正（ステップ③）

このステップでは、対話形式でJSONデータを開き、自動抽出された `speaker` および `company` フィールドの誤りを手動で修正します。

#### 1\. 修正スクリプトの実行

`update_data_sched.py` を実行し、データIDを入力して修正作業を開始します。

| 項目 | 詳細 |
| :--- | :--- |
| **インプット** | `output_2025_with_id.json` |
| **アウトプット** | `output_2025_with_id.json` **(上書き)** |
| **実行コマンド** | `python update_data_sched.py` |

#### 2\. 修正時の注意点

データを修正する際は、以下の点に厳密に従ってください。

| 注意点 | 詳細 |
| :--- | :--- |
| **クォーテーション** | 入力する企業名や人名は、必ず **シングルクォーテーション (`'`)** または **ダブルクォーテーション (`"`)** で囲んでください。 |
| **カンマ区切り** | 複数の項目を入力する場合は、カンマ（`,`）で区切ってください。 |
| **形式** | 入力例: `'John Doe', 'Jane Smith'` または `"Google", "Hitachi, Ltd."` |
| **修正なし** | 修正しない場合は、`s` または何も入力せずに `Enter` を押してください。 |
